# 📸 GalleryApp

An Android application built with **Kotlin** and **Jetpack Compose** that loads and displays images directly from the device storage in a modern, responsive UI.

---

## ✨ Features
- Built entirely with **Jetpack Compose** for a declarative UI.
- Fetches and displays images stored on the device.
- Smooth scrolling and grid layout for image previews.
- Lightweight, fast, and optimized for performance.

---

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM (ViewModel + StateFlow)
- **Image Loading:** Android MediaStore API

---

1. Clone the repository:
   ```bash
   git clone https://github.com/Rishabh-alt-hash/GalleryApp.git

3. Build and run on an emulator or physical device.
